Reactive Pipeline

Compose plain functions into a lazy, typed, promise-aware pipeline.

pipe composes plain functions into a single callable function. Composition is lazy — nothing runs until you invoke the returned function — and the result is typed end-to-end.

pipe(...functions)

Creates a function that pipes input through a series of functions.

Key properties:

  • Up to 10 function compositions
  • 0–3 parameters per function
  • Returns a callable function carrying extra methods (see below)
  • Always returns a promise when awaited

The returned function

The object returned by pipe is callable and carries three control methods:

MethodSignaturePurpose
replace(replacements: Array<[number, Function]>) => PipeFunctionSwap individual steps by index
replaceUndo() => PipeFunctionRestore the original steps
context(ctx: unknown) => PipeFunctionInject context into pipeContext steps

exitPipe<T>(value: T)

Exits the pipeline early and returns a wrapped value instead of running the remaining steps.

Promise support

Steps may return promises; pipe awaits each one before continuing.

Type safety

The pipeline preserves function signatures across compositions, infers return types, and detects monads to compose them automatically. Parameter counts are validated at compile time (0–3 per function).
