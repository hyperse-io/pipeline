Middleware Engine

Ordered, context-aware middleware chains with automatic error propagation.

The middleware engine is a Koa-style pipeline. Middleware functions run in the order they were added, share a single context object, and can short-circuit or handle errors downstream.

Pipeline<T>

A middleware container and invoker.

Prop

Type

T is the context type shared between middleware functions.

Middleware<T>

The signature every middleware function must satisfy.

Basic usage

Error handling

Because next accepts an error, error-handling middleware is simply middleware that checks its third argument. Register the handler after the middleware it should protect, and error propagation flows in declaration order.

Error parameter position

The error argument is always the third parameter. A middleware that declares it opts into error handling for everything the previous middleware forwards.
