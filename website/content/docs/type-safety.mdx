The library is written in TypeScript and designed so that composition never
degrades the types you started with.

## Guarantees

- **Generic inference** for context and return types
- **Signature preservation** across pipeline compositions
- **Monad detection** so composition stays typed
- **Parameter count validation** — 0 to 3 parameters per function
- **Return type inference**, including `exitPipe` detection

## Inference in practice

```typescript
import { pipe } from '@hyperse/pipeline';

const run = pipe(
  (n: number) => n + 1,
  (n) => n.toString(),
  (s) => `${s}!`
);

const out = await run(41);
// `out` is inferred as string: "42!"
```

## Context typing

`pipeContext` carries the context parameter through to `.context()`:

```typescript
import { pipe, pipeContext } from '@hyperse/pipeline';

const run = pipe(
  () => 1,
  pipeContext((ctx: { factor: number }) => (n: number) => n * ctx.factor)
);

run.context({ factor: 10 });
const out = await run();
// `out` is inferred as number
```

## Exit narrowing

`isExitPipeValue` is a type guard, so a union return type narrows correctly when
you branch on it.
